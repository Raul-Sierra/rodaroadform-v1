# RodaRoad Form

Diari de ruta digital per a conductors de camió.

## Funcionalitats

- Registrar activitat d'una jornada
- Seccions: Conductor, Vehicle, Viatge
- Carregues i descarregues dinàmiques
- Fotos i adjunts
- Generació de PDF
- Suport multilingüe (ES, CA, EN)

## Tecnologies

- HTML5 / CSS3 / JavaScript (ES Modules)
- CSS Custom Properties (variables)
- Sense frameworks ni build tools

## Desenvolupament

1. Obrir `index.html` amb Live Server al VS Code
2. O executar `npx serve` a la carpeta del projecte
